# Playbook de shots — referencia consolidada

El procedimiento duplicado de esta ruta está retirado. Usa [AGENTS.md](../AGENTS.md) para
navegación y autonomía, la [Regla 19](./CONSTITUTION.md) para verificación y el
[modelo operativo](./AGENT_OPERATING_MODEL.md) para comandos por superficie.

El [roadmap](./PRD/PLAN_SHOTS.md) define alcance, secuencia y gates. Los planes en `docs/plans/`
registran decisiones y evidencia de su shot; `python scripts/new_shot.py SHOT-XX` es un scaffold
opcional, no una orden de iniciar un shot ni una aprobación humana adicional.
