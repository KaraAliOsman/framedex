# Dated redesign evidence

Reports in this folder describe specific refs and dates. Use
[v1 acceptance](acceptance-2026-10-12.md) for the completed program's scope
and limits; inspect current source before treating an earlier finding as live.
The current UI rules are in [the constitution](../design/CONSTITUCION.md),
and task routes are in [the wiki](../wiki/index.md).

[The evidence map](captures/README.md) separates retained acceptance from
archived captures. Some PNG/PDF/JSON files are regression inputs read by
scripts; check consumers before removing or moving them. Exploratory output
belongs in `.run/`; promote only evidence needed to explain a change.

Broad ripgrep discovery omits historical reports and capture payloads.
Open a known file directly or scope `rg --no-ignore` to the needed folder.
